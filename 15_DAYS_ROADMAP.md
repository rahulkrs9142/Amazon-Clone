## ⚡ How to Push Each Day

Every day, just run this single command in your project folder (`e:\Amazon Clone`):

```powershell
powershell -ExecutionPolicy Bypass -File .\daily_push.ps1
```

It will automatically:
1. Detect which day is next (Day 2, Day 3, etc.)
2. Stage that day's files and features
3. Create the corresponding commit message
4. Push to your GitHub repo (`https://github.com/rahulkrs9142/Amazon-Clone.git`)
5. Advance the day counter for tomorrow!
